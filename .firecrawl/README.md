# .firecrawl — Competitor Research Artifacts

## Compliance Guidelines

**Do NOT commit verbatim scraped content.** All competitor research files in this directory should contain:

- Original analysis summaries written in our own words
- Feature comparisons (bullet lists or tables)
- Strategic gaps and opportunities
- Metadata: `analysis_date`, `source_urls`, `author`, `confidence_level`
- Links to live pages instead of embedded full copies

**Acceptable extracted fields:**
- Feature names and capabilities (described in our own words)
- Pricing tiers and plan names
- Screenshot references (with permission noted)
- Source URL and capture date

**Not acceptable:**
- Full-page HTML or markdown dumps
- Verbatim marketing copy
- Scraped URL lists without documented authorization
- Embedded competitor logos or images

**Before storing full-page content**, consult legal for fair use and authorization.
